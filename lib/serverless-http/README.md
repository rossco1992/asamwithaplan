# Vendored serverless-http adapter

This workspace contains the runtime files from
[`serverless-http` v4.0.0](https://github.com/dougmoscrop/serverless-http/tree/v4.0.0),
used to adapt the existing Express application to Netlify's AWS-compatible
Functions event format. The upstream package has no runtime dependencies.

The source is included with its original MIT license in `LICENSE.txt`. Keep the
version, source files, declaration file, and license together when updating it.
